# StuHelper Catalog

课程目录与可信选课记录模块，提供 Go 服务、PostgreSQL Repository、HTTP Handler 和生成的 Go/TypeScript SDK。学校接入协议与真实数据由私有适配器维护。

课程、教师、学期、学期开课、教学班、授课关系和排课分别保存。公开课程列表按课程去重，支持开课学院、类别、性质及教师筛选。客户端课程列表不展示学期；学期保留在资格证据和课程评价中。

导入每页最多 500 个对象与选课记录，事务中一起保存历史、审计和 outbox。失败或遗漏记录不会删除旧数据。来源修订防止旧数据覆盖，人工更正继续保留。学生选课接口只读取认证请求人的记录。

课程与教师摘要返回所属学校、院系、分类及关联数量。批量引用查询最多接收 100 个 ID。开课与教学班接口按同一条授课关系筛选，教学班详情保留合授教师和时间地点。人工更正支持清除未知字段，并使用修订号拒绝覆盖并发修改。

目录维护支持合并与停用。合并先预览并核对修订，目标资料继续使用，旧 ID、源名称及历史保留。公开查询解析旧关联，评价统计按合并后的课程去重。目标别名容量不足时，预览拒绝合并，避免丢弃源名称。停用不会删除历史，目录默认隐藏停用对象。

规范化导入支持差异预览，区分新增、更正、保留人工值、冲突与未关联记录。预览使用回滚事务；确认令牌同时绑定输入和当时数据，过期预览拒绝写入。学校抓取、定时同步和来源任务仍由共享接入能力负责。

公共目录详情、搜索、批量引用、摘要和合并解析均要求当前内容准入。应用通过 ReadAccess 提供服务学校与当前资格，缺少依赖时拒绝读取。本人选课只按登录和归属授权，管理员使用独立的 /catalog/admin 读接口并检查维护范围。

## 使用与检查

先维护 `contracts/catalog.openapi.json`，再执行 `make generate`。应用注入认证结果与可维护学校范围，不能由客户端指定操作人。SQL 仅位于 postgres 包。

```sh
make setup
bash scripts/check-with-postgres.sh
```

检查脚本建立独立、仅 Unix socket 可访问的 当前稳定 PostgreSQL 集群，退出时清理。测试使用独立数据库与运行身份，检查事务回滚、并发幂等、学院分类、教师归属及禁止越权访问。

迁移身份执行 `postgres.Schema`；运行身份仅获得 catalog schema 的读写权限，不得创建数据库对象或访问其他模块 schema。`postgres.CheckRuntime` 在应用装配时检查权限。

当前首次建库迁移已验证。存量生产迁移、学校持续同步、运行库备份和恢复演练仍待实际环境验收。outbox 与业务同事务持久化并通知 OutboxChannel（catalog_outbox）。relay 通过 PendingOutbox 读取待发送事件，并传入需要排除的退避或人工处理主题。消费者持久提交后调用 ConfirmOutbox。通用跨服务 relay 由 backend 装配。

业务规则见 [课程与评价规格](https://github.com/StuHelper/stuhelper-next/blob/develop/docs/spec/academic-content.md)。

本人名称查询 /catalog/me/references 只返回本人当前或历史选课记录关联对象的 ID、类型和名称，单次最多 100 个 ID。任一 ID 不属于本人记录时拒绝整次请求。名称接口不返回简介、评分、统计或排课详情，公共目录仍检查内容准入。

## 本人课表投影

MySchedule 是供模块使用的公开接口，只读取当前账号的有效选课记录和相应教学班排课。使用批量名称与排课查询，不查询其他账号记录，也不将内容准入失效放宽到公共目录。

每页最多 100 个选课记录，每条最多 100 个排课，一页排课最多 1000 条。超过范围返回 unavailable，调用方减小分页后重试。没有排课时返回空 meetings，不据此判断用户空闲。

结构化排课、学校学期作息、本人 HTTP 课表和 iCalendar 导出见[实现规格](docs/spec/my-courses.md)。导入预览同时返回解析结果与原文，未知时间保持缺失。

## 审计与搜索来源
