# 课程换号与独立英文名

## 对象与搜索

课程使用当前课程号生成的稳定 ID。`code`、名称、学分和 `hours` 使用目标课程资料。`english_name` 单独保存英文名，`former_codes` 保存曾用课程号，`former_names` 保存不同于当前名称的曾用名。未知学时保持空值。

`aliases` 保留给学院等对象。学院曾用名继续使用该字段。课程英文名和曾用课程号不写入该字段；课程页面使用英文名、曾用课程号和曾用名三项标签。

课程目录、普通列表与搜索文档同时包含当前名称、课程号、英文名、曾用课程号和曾用名。每个字段独立执行字面子串匹配，不把相邻字段拼接成新的搜索词。

## 来源映射

`POST /api/v1/catalog/course-identities` 接收学校、来源、来源修订和最多 5,000 对原课程 ID 到目标课程 ID。调用方需要该学校的导入权限。两端必须存在，属于同一学校与来源，且已经导入同一来源修订。

映射必须一对一。缺失端点、自指、链、环、重复源、重复目标、跨学校与冲突重定向均被拒绝。一次请求在同一学校写锁和数据库事务内完成，历史、审计、outbox 与永久幂等回执一起提交。同键不同内容返回冲突。

原课程记录和外键保留。旧 ID 的 resolution 返回目标资料与 `canonical_id`，其 `ids` 列出等价 ID。同学期开课通过重定向去重，选课保留本人、教学班、教师和来源证据。目录截止条件按合并后所有开课计算。

完整来源导入在同一个 `RunDirectoryImport` 中先写入各页，再应用课程映射，最后重建并发布目录。中间失败保留上一份公开投影，重试沿用相同输入，不发布部分课程关系。

## 字段迁移与回退

导入选项 `separate_course_names=true` 明确声明旧来源的课程 aliases 仅用于英文名。来源英文别名被独立字段替代，历史人工课程名称移入 `former_names`。学院等对象的 aliases 保留。未声明该选项的来源沿用兼容导入规则。

迁移新增搜索函数和独立的 v2 索引，保留原函数与索引。课程原记录、选课、评价和资料引用不删除。回退保留已应用的映射及切换后新写入，不覆盖数据库快照，也不拆散已经统一的课程。

二进制回退需要使用能接受课程搜索字段的消费者，并暂停旧格式目录导入。目录与搜索可从保留的业务事实重建。完整产品回退组合由发布方固定版本后演练。
