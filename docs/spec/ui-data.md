# 目录与本人课程摘要

## 范围与接口

GET /api/v1/catalog/directory 提供课程和教师目录、分页、类别数量、学院分组与课程性质分面。kind 必填，sort 为 hot、recommend、reviews 或 name，limit 为 1 至 100。支持 department_ids、category_ids 多选与 credits_min、credits_max 学分区间筛选。

课程行批量带出对象、当前筛选命中的学院和类别、可见评价数、五维档位、推荐等级及热度。课程可能属于多个开课学院、类别或性质，每个分面内部按课程去重。未知学分课程不匹配学分区间筛选。

total 是当前筛选的目录对象数。facet_total 与 category_facets 排除 category_id 和 category_ids 自身条件，其他条件保持生效。department_facets 与 nature_facets 保留全部当前筛选。每个分面返回对象数及可见评价合计。

课程目录按规范课程去重。教师目录按教师汇总，合授评价可能计入多位教师。同一对象可属于多个分面，分面数量不能直接相加。类别成员与目录分类一起缓存，review_count 每次使用当前评价聚合。

同一课程的学院、类别、性质和教师条件必须在同一开课或教学班上成立。院系分面只列能关联到有效院系对象的开课学院。没有任何开课学院的课程保留在「全部」列表和总数中。

热门排序按热度、评价数、ID。推荐排序按四档等级、热度、ID。评价数排序按评价数、热度、ID。名称使用确定性的 C 排序。数字降序，ID 升序。游标绑定本人、学校、筛选、排序、指标配置和投影版本。

跨北京时间零点可继续翻页。投影重建后旧游标返回 409，客户端重新读取首页。

指标在翻页时实时读取。浏览期间热度或评价变化可能改变相邻页排序，重新载入列表可取得当前顺序。游标不包含精确评分或个人统计。

学校可合并分类并隐藏分类筛选项。合并后分面按课程 ID 去重，停用的旧分类筛选链接返回空结果。隐藏筛选项保留课程、详情和其他筛选下的成员关系。

产品装配启用教师标记与目录投影。列表、分面和总数只接受当前投影中的教师。授课依据受截止学期限制，官网依据独立生效。教师筛选参数本身也须通过当前目录读取。

## 热度与数据来源

课程和教师目录按全部历史计算热度。浏览和收藏从开始记录之日起累计各对象的有效日汇总，评价取当前可见的有效评价数。

浏览、收藏、评价默认权重分别为 1、3、5。DirectoryConfig 允许配置三个非负权重，至少一个权重大于零。

浏览来自 catalog 日聚合。评价数量和等级来自 reviews 的公开批量接口。收藏来自 favorites 的日净新增聚合，每日下限为零，跨日取消计入取消日。聚合不包括讨论互动，也不搬运旧目录别名的历史浏览与收藏。

reviews 和 favorites 由 backend 注入 DirectoryMetricProvider。catalog 不访问其他模块表。缺少这些依赖时目录能力不可用，已有基础目录接口继续按原规则提供服务。推荐配置和教师等权规则由 reviews 拥有。

## 查询、缓存与一致性

目录成员、分类关系、非零筛选项和默认候选集合持久保存在 catalog 投影表。全量规则、学期排序和失败保留见[可展示目录投影](directory-projection.md)。普通读取不再展开源目录的大表关联。

进程内缓存已发布投影的读取结果，无筛选默认候选按版本常驻缓存，筛选查询使用最多三十二项 LRU 缓存池，总空间上限 64 MiB，五分钟到期。每次请求读取当前投影版本，只有同版本结果可复用。成员、引用展开和分面共享一个数据库快照。

评分、收藏、浏览和当前内容权限每次重新读取。目录缓存不保存个人数据、评分或授权决定。相同条件的并发读取合并，等待支持取消。默认候选直接加载预计算结果，带筛选的请求在投影关系上计算分面。

目录对象最多十万个，分类关系最多五十万条，缓存原始 JSON 最多 32 MiB。超限返回不可用。查询次数不随单页行数增长，跨模块统计仍通过公开批量接口取得。

## 最近访问课程

GET /api/v1/catalog/me/recent-courses 读取本人最近课程。PUT /api/v1/catalog/me/recent-courses/{id} 使用服务端时间记录访问，DELETE 集合清空本人记录。课程详情和摘要读取也会记录访问，失败只影响访问记录并输出固定错误类型。

每人保存最近二十门不同的规范课程。持久字段只有账号分区、课程 ID 和访问时间。同账号写入与清空串行执行，重复访问更新时间，不新增重复行。合并后的课程去重显示。

记录在九十天边界立即不可读。backend 每五秒调用有界清理，每批最多一千条。写入时同时删除本人的过期记录及超出二十门的记录。清空只要求本人登录，资格撤销后仍可清空。

读取和写入最近课程时均重新检查当前内容准入和目录状态。只有当前投影中的课程可显示并累计浏览热度。

资料数量通过 resources 批量端口查询，子超时为一秒。端口缺失、出错或超时时仍返回已记录课程，`resources_state` 为 `unavailable`，`resource_count` 为 null。

## 下一上课日与待评价候选

GET /api/v1/catalog/me/next-class-day 使用现有本人选课来源和课表，单次请求只刷新一次来源并限定当前学校，返回下一次仍未结束的课程所在日期、时区、节次、教师与地点。已结束历史学期不因缺少作息配置阻断计算，当前学期存在有效排课时兼容无固定排课课程，任课教师保留未公开标记姓名并省略简介。没有后续课程为 empty，全部缺少排课或缺少授权为 unavailable。

`OwnSummaryAccess` 单独授权显示本人选课摘要。缺少端口时，下一上课日与待评价候选返回不可用。StuHelper v0.1.31 的 backend 未装配此端口。评课资格来源用于验证提交资格。

同一个授权来源通过 MyReviewCandidates 向 reviews 提供本人课程与学期候选。缺少来源时不能读取旧选课缓存代替授权。每次最多两千条候选，只返回课程和学期名称，不返回学生身份或选课证据。

## 目录筛选选项

GET /catalog/filter-options 接收 kind=course 或 teacher 和可选 school_id。学校来自当前准入，接口不接受搜索或其他已选条件。课程返回开课学院、类别与性质，教师只返回院系。每项包含 id、name 和去重 count，总数为 total。

选项只包含至少一个可见对象的分类。课程对象、开课与教学班继承、停用状态、别名归并和学校范围沿用目录查询，教师另检查当前持久标记。没有成员、已停用或已合并的分类不会作为选项返回。

选项和总数直接读取已发布投影中的预计算值。课程、别名、标记或配置改变并成功重建后，下一请求读取新版本。当前学校与资格每次重新检查，热度和评价依赖不影响选项读取。

已选择其他条件后的动态隐藏由客户端使用目录分面计数处理。选项接口始终描述完整可见目录，避免选择条件改变静态选项集合。
