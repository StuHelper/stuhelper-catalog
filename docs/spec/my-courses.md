# 结构化课表与日历

## 排课与导入

schedule 对象的 schedule_time 包含 weekday（周一为 1）、start_period、end_period 和 weeks。节次范围为 1 至 30，周次范围为 1 至 60，周次集合不重复。单双周直接表达为周次集合。缺少结构化数据时，客户端显示“未提供”。

导入支持明确的结构化字段，也识别 `周一 第1-2节 第1-16周(单)`、单节课 `第5节`、单周课 `第8周`、递增跳周段 `第1-8,10-16周` 及全角 `（单）/（双）` 后缀。无法解析或周段重叠乱序的文本保留在 time_text，结构化字段保持缺失，显式无效结构返回 invalid_input。

## 本人查询与日历

GET /api/v1/catalog/me/schedule 必须传 term_id。接口仅查询本人授权范围内的有效选课，返回课程、教学班、教师、地点、时间和可用作息。作息缺失时省略 timetable，客户端显示“未提供”。

选课、课表、日历、本人引用、下一上课日和评课候选的个人数据均受当前学校数据授权限制。授权范围覆盖截至学期及以前的本人记录。超出范围的指定学期在查询个人来源和仓储前拒绝。

课表分页上限为 100 条选课，每条最多 100 个排课，每页最多 1000 个排课。超限返回 unavailable，客户端可缩小分页。历史学期按 term_id 隔离。

GET /api/v1/catalog/me/schedule/calendar 导出该学期完整 iCalendar。最多处理 100 条选课和 10000 个事件，超限返回 unavailable。没有选课时返回空日历。任一选课缺少排课、结构化时间或所需作息时，返回 HTTP 422 schedule_incomplete，避免静默遗漏课程。

日历按星期和周次展开本地日期，使用学校 IANA 时区转为 UTC DTSTART 与 DTEND。夏令时造成的无效或歧义时间返回 schedule_incomplete。UID 由请求人、学校、学期、教学班、排课 ID 和周次确定，调整作息保持 UID。文本转义、CRLF 和按字节折行符合 iCalendar 输出要求。

## 学校学期作息

GET 和 PUT /api/v1/catalog/admin/schools/{school_id}/terms/{term_id}/timetable 要求 catalog 管理能力和学校维护范围。配置包含学期第一周周一日期、IANA 时区和各节次开始结束时间。节次按编号和时间递增，不允许重叠或跨午夜。

配置按学校和学期独立持久化。创建传 revision=0，更正传当前修订号。并发更正返回 conflict；紧接成功写入的相同旧修订请求返回原结果。不存在的配置返回 not_found。

作息写入、审计与 CloudEvents outbox 在同一事务提交，并通知 catalog_outbox。审计记录操作者、学校、对象和修订。作息事件通过 PendingOutbox 读取，消费成功后调用 ConfirmOutbox。sent_at 为空表示待发送，确认后保留首次确认时间。

学校数据授权按当地首周周一零时切换学期。两个起始日之间的假期属于前一学期。正式暑期学期按其起始日纳入。起始日缺失或冲突导致无法判定时，认证模块保留原范围。

## 验收场景

| 场景 | 结果 |
| --- | --- |
| MC-01：本人有选课 | 返回课程、教学班、教师与结构化排课，无法读取他人课表 |
| MC-02：切换学期 | 查询与日历均按学期隔离 |
| MC-03：时间或作息缺失 | 查询保留原文，日历返回明确缺失结果 |
| MC-05：单双周与时区转换 | 展开正确日期，保持稳定 UID，正确转义和折行 |
| MC-06：管理作息 | 校验范围及修订，重复和并发写入不重复产生审计，事务失败回滚 |
| MC-SD-02：截至学期前后均有选课 | 只查询已授权学期。指定下一学期时零个人来源调用 |
| MC-SD-03：学期首周、假期及日历冲突 | 以学校时区计算界限。缺失或冲突返回暂不可用 |

`module.yaml` 登记隔离 PostgreSQL 用例。运行身份访问 catalog 数据，迁移身份单独执行 Schema。

## 上课提醒接入

`MySchedule` 和 `ExpandSchedule` 供宿主读取本人课表及稳定 UID。作息更新与导入事件通过 catalog outbox 提供。上课提醒消费者、提醒偏好及实际通知投递仍待接入验收。

## 学期顺序

学期对象提供 term_order_key，本人选课和课表接口在 include_term_order=true 时返回该字段，使用自然年乘十加季节：春为一、夏为二、秋为三。例如 20243 表示 2024 年秋季，与目录截止学期使用同一排序规则。名称只用于显示，不参与排序。

学期选项及选课记录按排序键倒序、ID 升序。选课的 after 仍使用上一页最后一个选课 ID，游标必须属于当前用户并符合当前筛选。已知时间相同的记录按 ID 稳定分页。

学期排序未知的选课记录排除在个人读取范围之外。公开目录投影继续按自身规则隐藏无法解析、早于目录截止学期或没有可见开课的学期。

排序键只在读取结果中补充，选课原始记录和导入请求继续使用原序列化格式。升级前的导入幂等回执可直接重放，导入入口拒绝提交只读排序字段。

选课和课表 HTTP 请求默认保持旧 Enrollment 结构，未请求排序字段时省略该字段。include_term_order 只接受单个 true 或 false，排列顺序始终采用结构化时间。
