# 本人选课来源与目录刷新

应用可通过 EnrollmentSource 注入可信的本人选课来源。catalog 向来源传入已认证账号，来源返回该账号、学校和来源的完整快照。客户端不能指定其他账号或直接提交学号取得资格。

本人选课、课表和本人引用查询在读取前刷新快照。来源错误返回 unavailable，失败不清空已有记录。来源返回的账号必须与请求人一致，单个快照最多 2000 条。

ReplaceOwnEnrollments 是维护用 Go 接口，要求导入能力和对应学校范围。快照只能修改指定账号、学校和来源的数据。未出现在完整快照中的旧记录停用，其他来源和其他账号的记录保留。

快照、来源标记、审计与 outbox 在同一事务保存。普通导入与本人快照共用学校锁，获取锁后重新读取对象。快照上限只约束当前记录，停用历史不占用名额。

相同版本和内容重复执行返回原结果，相同版本不同内容被拒绝。旧修订不能覆盖新修订。有效绑定重新出现时可以恢复同一来源修订的记录。

普通目录 Import 仍以每页 500 条为上限，遗漏对象不作为删除。已保留的导入回执不因经过 24 小时失效。后续批次的公开字段没有变化时，只推进来源修订，保留公开对象、历史与搜索版本。

## 验收场景

| 编号 | 条件与预期结果 |
| --- | --- |
| CAT-SOURCE-01 | 并发和超过 24 小时的重复快照只产生一次结果，错误引用使整批回滚，停用仅影响同账号同来源。 |
| CAT-SOURCE-02 | 本人读取刷新来源；来源故障时选课、课表和引用返回不可用，已有记录保留。 |
| CAT-SOURCE-03 | 相同目录的新批次保留公开版本，并拒绝较旧来源覆盖。 |
