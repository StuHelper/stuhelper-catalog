# 可展示目录投影

## 可见范围

默认截止学期为 2023 秋，配置由服务端提供。课程在截止学期及以后有有效开课记录时进入列表、搜索、热门和推荐。停用对象及已合并源对象不单独展示，关联统一指向规范对象。

教师满足以下任一条件即可展示：在截止学期及以后有有效任课关系，或与官网唯一匹配。授课依据要求任课关系、教学班、开课及课程均有效，官网依据仍检查匹配姓名和院系。

投影只保存可展示课程。仅在截止学期以前开课的课程，其详情、评价和写评价入口统一返回不存在。课程源记录仍供同步维护使用，公开读取不回退到源表。

每次公开读取继续执行当前内容准入和学校检查。投影只保存目录事实，不保存账号权限、选课证据、评分、浏览、收藏或资料数量。

## 展示规则与体育项目

`directory_policy` 可配置课程名称排除、类别名称排除、类别别名和体育项目。规则与截止学期一起保存在目录版本中，重建成功后同时生效。名称匹配忽略首尾空白与字母大小写，其他学校未配置时保持原行为。

类别排除按截止学期内的有效分类关系判断。一门课程命中排除规则后，全部公开入口返回不存在。历史教学班的类别不单独排除当前课程。类别别名只改变投影，筛选选项、详情标签和去重计数使用同一规范类别。

体育项目由教学班的 `sports_project_code` 与配置中的 `source_codes` 对应。项目名称和稳定 `key` 来自配置，不根据场地、教师或备注猜测。项目更名保留 key，归并代码前须确认既有评价的归属影响。

目录将体育课程替换为 `kind=course`、`course_type=sports_project` 的项目条目。项目 ID 由学校和 key 确定，跨学期保持一致。项目与学期构成开课条目，教学班和授课关系保留原 ID，课程关联改指向项目。

同一项目下列出其有效教学班的教师。缺少项目代码、代码未配置或没有有效教师的教学班不展示，重建报告分别统计原因。原编号体育课程没有指向项目的重定向，其旧链接返回不存在。

目录保存版本化的原课程、教学班与项目关系。原始课程和选课事实保持不变。评价证据同时核对本人、原课程、原学期和教学班，只返回该项目当前教学班与本人选课记录共同确认的教师。

评价继续使用 course 类型，目标为项目 ID，并要求一个教师。同一编号课程中的其他项目、同一项目中的其他任课教师及其他账号均不能提供资格。项目的完整目录与个人评价资格分别查询。教师回复所需的历史任课依据也按明确项目代码归纳，保留截止学期以前的已知项目事实。

新增两张映射表随目录版本保留和清理，受现有投影对象及分类关系上限约束。迁移后重新授予 catalog 运行身份权限；业务身份不能访问其他模块的数据。

## 学期顺序

学校适配器把可靠的学年与学期编号转换为自然年和季节，调用 SaveTermOrders 保存。catalog 不解析显示名称，也不推断学校的学期编号。

排序键为自然年乘 10，加春 1、夏 2、秋 3。学期选项只返回截止学期及以后且有关联可见课程的学期，按排序键降序、ID 升序。客户端保持服务端顺序。

无法解析的学期保存固定原因与零排序键，不进入选项和有效开课关系。缺少结构化元数据时记录 missing_term_order。历史名称仍可用于解释既有记录。教师回复需要的可见课程完整历史任课关系另行投影，按已完成来源批次更新，保持原披露规则。

## 构建与切换

RunDirectoryImport 登记持久导入批次，再逐页导入。完整来源成功后重建投影并提交批次完成状态。中途失败、超时或进程退出时继续使用旧投影，部分源记录不对外发布。

导入进行中或失败后，其他来源写入和配置重建返回冲突。失败批次可重试，运行中批次的租期为两小时。租期到达后新执行可接管。同一来源批次的每次执行具有独立标识，写入和发布同时检查标识、运行状态及租期，已完成或被接管的执行不能继续写入。

官网刷新完整导入、普通目录更正、合并、停用和结构化学期变化都会重建已有投影。截止配置与新投影同时发布，配置校验或构建失败保留旧配置及旧版本。

构建持有目录来源写锁，读取继续使用旧版本。各阶段完成后校验数量和关联条件，再在同一事务切换学校的版本指针。失败原因以固定代码持久保存，不记录来源字段或 SQL 参数。

新版本包含对象、有效开课与教学班分类、课程与教师关系、筛选选项、默认候选集合、别名、详情汇总和搜索文档。数据按版本隔离，公开列表不再逐次展开五十五万行源表。

大批写入后通过固定的 analyze_directory_projection 函数更新投影表统计。函数不接受参数，仅分析列明的投影表。运行身份只获此函数的执行权限，不能借此访问其他模块或创建数据库对象。

## 读取与保留

产品 Repository 启用 RequireDirectoryProjection。缺少已发布版本时，课程与教师目录返回不可用。受信维护入口可读取原始目录，学校名称检索和本人历史证据保留各自的授权与读取方式。

默认目录候选直接读取预计算结果。筛选查询在版本化分类关系上执行，同一课程的学院、类别、性质、教师条件保持同一开课或教学班语义。零数量分类不进入选项表。

目录页和搜索快照绑定版本。目录重建使旧目录游标返回 409；搜索快照可继续读取保留的旧完整版本，版本被清理后返回 unavailable。当前搜索权限仍逐次检查。

只保留当前及前一完整版本，旧版清理由同一重建事务完成。已经开始的数据库一致快照仍可读到旧行。物理空间随 PostgreSQL 的常规清理复用，不另建共享缓存或外部存储。

单版本最多一百万个对象、十万个可见课程、十万个可见教师及五十万条分类关系。默认候选 JSON 每类最多 32 MiB。显式重建最多十分钟，加锁前设置十秒锁超时与一百秒单语句超时；HTTP 维护与导入写路由预留两分钟超时预算，普通读取与预览保持十五秒超时。

重建报告给出版本、配置、对象与关系数量、标记人数、无序学期数、数据字节数、含索引的表占用和耗时。数据字节数描述当前版本，物理占用包含保留版本、索引和可复用空闲页。

## 预计算取舍

| 对象 | 当前处理与原因 |
| --- | --- |
| 课程详情汇总 | 预计算课程与教师数量、前 20 条关联教师或所授课程引用、分类和学期关系；开课次数只供管理与受信读取 |
| 教师所授课程 | 保存按课程去重的关系，列表及详情通过投影索引读取 |
| 热门与首页候选 | 使用同一可见候选集合，评分和热度由所属模块实时提供 |
| 学院与分类别名 | 构建时解析规范 ID，并保存显示名与别名映射 |
| 学期排序键 | 由学校适配器解析，catalog 校验并持久保存 |
| 资料数量 | 保留 resources 的公开批量接口，避免复制其审核与删除规则 |
| 搜索文档 | 启用投影或已有投影版本时仅由版本切换按差异和墓碑写入 outbox，中途批次与已排除源对象不发源表事件 |

版本切换同时批量核对本校 `activity_buckets` 的可见性，被隐藏或恢复的课程与教师同事务更新日活动快照。

## 普通读取与教学班边界

普通目录只返回 school、department、category、nature、term、course 和 teacher。objects、directory、filter-options 请求 term_course、class、assignment 或 schedule 时返回 403 forbidden。

objects 与 directory 同时拒绝 class_id、term_course_id 筛选。

单项、摘要和 resolution 读取上述教学班对象时返回 404 not_found。lookup 将受限 ID 与未知 ID 一起列入 missing_ids，保留同批次中可见的课程与教师。授权仍使用当前内容资格与学校范围，客户端自报身份不参与授权。

公开摘要使用 PublicSummary，返回课程数、教师数及最多 20 条关联课程或教师引用，省略 offering_count。管理端沿用完整 Summary。课程按教师筛选、教师按课程筛选、学期选项、目录分面和非零筛选计数保持原语义，内部授课事实继续参与计算。

/catalog/admin 入口要求维护权限和学校范围，保留教学班读取。源表未命中的体育项目与合成展示分类会回退读取当前已发布投影，体育项目浏览计数按当前投影加共享锁并累计热度。/catalog/me 的选课、课表、名称与日历继续只返回本人记录。普通目录隐藏规则不修改导入、教师标记、投影构建或持久化数据。

Get、List、Lookup、Summary、Resolve、ReviewEnrollments 与 HasTaught 是供受信进程内调用的公开 Service 接口。reviews 通过这些接口核验选课、体育项目必选教师和教师回复资格。浏览器只能使用带身份与授权检查的 HTTP 入口。

搜索事件、重建快照和当前可见性查询只提供学校、课程和教师，文档不包含教学班、排课时间或地点。现有搜索协议已限制这些类型，本次保留协议并增加真实数据库回归。

## 验证场景

| 场景 | 通过条件 |
| --- | --- |
| CAT-PUBLIC-01 | 普通类型、详情、摘要、解析与批量入口隐藏教学班，双向关系及计数保留，本人课表隔离，管理与受信读取可用，搜索事件及快照不含教学班 |
| CAT-DISPLAY-01 | 排除、分类合并、项目归纳、教师归属和计数一致，旧链接不存在，原选课事实保留 |
| CAT-PROJECTION-01 | 截止边界、夏季顺序、未知学期、非零选项与列表计数一致，旧课程直接访问及关联入口返回不存在 |
| CAT-PROJECTION-02 | 重建失败保留旧版本及原因，配置变化同时改变公开授课依据 |
| CAT-PROJECTION-03 | 同步中断保留旧投影，重试完整切换，已完成、超时或被接管的执行不能继续写入 |
| CAT-PROJECTION-04 | 并发读取始终获得完整版本，搜索快照稳定，当前权限撤销后拒绝读取 |
| CAT-PROJECTION-05 | 相同五十五万行数据和评分条件下比较四种排序、教师、复杂筛选及选项的 p95 |

测试使用独立 PostgreSQL 与运行身份。生产行数、重建耗时、存储和接口延迟由部署负责人在正式同步后另行记录，隔离环境结果不作为生产测量值。
