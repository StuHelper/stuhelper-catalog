# 目录筛选与查询资源

课程与教师公开查询使用持久目录投影，规则见[可展示目录投影](directory-projection.md)。基础列表仍按 ID 游标分页，单页最多 100 条，名称引用通过批量接口取得。

## 查询语义与资源

课程学院、类别和性质依次继承教学班、学期开课和课程值。同一筛选组合必须在同一个开课或教学班成立，不能拼接不同教学班。没有学期或教师条件时，可见课程自身的分类也可匹配。

投影保存有效课程、教师、开课关系、规范别名、分类和预计算候选。带教师、分类或搜索条件的查询使用投影索引，默认目录直接读取预计算候选，不在请求期间展开源目录的大表关联。

名称、代码及每个别名内分别执行不区分大小写的字面子串匹配。百分号、下划线与反斜杠没有通配含义，也不跨字段拼接匹配。

当前内容准入和服务学校仍在每次请求时检查。投影及进程内读取缓存不保存用户权限，不延长资格有效期。管理员读取隐藏对象继续检查独立维护范围。

## 迁移与统计

postgres.Migrate 保留源目录的分类、关联覆盖和名称索引，用于维护、资格事实和回退。投影迁移新增版本表、关系索引与固定统计更新函数，不删除原对象、历史或切换后的业务写入。

构建分阶段更新投影表统计，完成后发布新指针及统计。这样避免新版本被估成极少行，导致汇总反复扫描同一分类结果。学校关联使用本轮明确的学校参数。

源目录维护路径保留原参数化查询、覆盖索引和同教学班筛选。它不作为产品公开目录缺少投影时的回退路径。缺少已发布投影时，公开课程和教师查询返回不可用。

## 失败诊断

列表记录 authorization 与 list 阶段的慢请求和失败，包含固定原因与耗时。数据库事务开始阶段另记录连接池使用量、上限与累计等待次数。池指标是进程汇总值，不能单独证明某个请求等待了连接。

诊断区分上下文取消、截止时间、数据库取消查询、连接耗尽、锁不可用和数据库不可用。HTTP 继续返回稳定的 unavailable；日志不包含查询词、对象 ID、账号、DSN、SQL 或驱动原始错误。

## 验证

ACAD-01 登记源目录维护筛选、字面搜索、同教学班匹配、存量迁移与诊断脱敏测试。规模测试使用 557,205 个合成对象和同量历史记录，5 个请求并发、3 个数据库连接，覆盖课程与教师的 32 组查询。

补充测试覆盖任课集中于少量课程的分布、教师与分类不能跨教学班匹配，以及常见类别在有界首段没有命中时的完整回退和游标。生产测量单独记录数据库版本、资源限制、连接池初始化与查询样本。

测试先在旧表上创建索引，再重跑迁移并核对对象与历史数量。性能输出记录 p95、最大耗时和错误数；运行环境与实际生产验收由 ops 的接续说明记录。目标为约定负载下各组合 p95 小于 300 ms。

CAT-PROJECTION-05 使用相同的 557205 个合成对象、同量源历史及确定性评分，对比源表读取和投影读取。分别报告首次读取和二十次后续请求的 p95，并核对两侧计数。生产延迟单独验收。
