# 目录筛选与查询资源

课程与教师列表使用 ID 游标分页，单页最多 100 条。查询多取一条判断是否有下一页，不计算全目录 COUNT。列表不逐条调用摘要接口；名称引用继续通过最多 100 个 ID 的批量接口读取。

## 筛选语义

课程院系、类别与性质依次使用教学班、学期开课和课程值。同一筛选组合必须在同一个开课与教学班内成立，不能拼接不同教学班的条件。没有学期或教师条件时，课程自身完整匹配也可返回。

常用课程、教师列表按实际条件生成参数化查询。分类索引先取得可能匹配的课程，组合条件取候选交集，再核对继承规则。教师筛选同时核对当前任课关系。合并旧 ID 继续解析，停用对象默认隐藏。

按教师筛选课程先固定该教师的任课集合，再关联教学班、开课和课程。无分类条件时先去重开课，只读取覆盖索引中的关系键；存在分类条件时，继承值仍须来自同一任课教学班。

列表按实际参数规划查询，在本次事务内关闭 JIT，避免编译开销占满小型数据库的 CPU 与内存。其他事务沿用数据库原配置。

查询仍先执行当前内容准入并限制服务学校。索引只帮助查询定位对象，不保存用户权限，也不延长资格有效期。管理员查看停用对象继续检查维护范围。

## 索引与迁移

postgres.Migrate 执行 Schema 中的分类、关联覆盖索引与 GIN 名称索引，提交后执行 VACUUM (ANALYZE) 更新统计与可见性信息。分类字段已有独立列，运行身份只能访问业务数据，迁移由独立迁移身份执行。

课程和教师分别使用名称 GIN 索引，减少同一短词命中其他对象类型后的回表读取。教学班和开课的覆盖索引保存关系键与分类字段。原有索引保留，旧程序与回退继续可用。

分类候选先去重开课。至多 512 个开课键执行索引定位，较大集合扫描一次开课覆盖索引再关联。内部 ASCII 键去重使用字节比较，外层查找与游标排序保留原数据库排序规则。

名称索引从名称、代码与别名产生单字和双字集合。该设计支持常见的一到两个汉字搜索，使用 PostgreSQL 内置 array_ops，无需安装扩展。[pg_trgm](https://www.postgresql.org/docs/18/pgtrgm.html) 对无法提取三字片段的模式会退化为全索引扫描。

没有其他筛选的名称查询先检查 ID 顺序中的前 128 条，已满足分页所需数量时直接返回，否则使用 GIN 查询。最多执行两次有界列表查询，保留完整结果与原游标顺序。

单独按课程类别筛选时，先用索引最多探测 4097 条教学班记录。常见类别检查前 512 门课程，结果不足一页则执行完整候选查询。该路径最多三次查询，不计算全目录总数，也不截断完整分页结果。

索引筛选后，查询仍在名称、代码及每个别名内分别复核不区分大小写的字面子串。百分号、下划线与反斜杠没有通配含义，不允许跨字段或跨别名拼接匹配。

索引随对象事务写入同步维护。更正、合并、停用和重新导入继续使用现有事务与修订规则，不增加独立缓存或后台重建队列。迁移可重跑，不改写业务数据。程序回退保留新增索引与切换后的写入。

## 失败诊断

列表记录 authorization 与 list 阶段的慢请求和失败，包含固定原因与耗时。数据库事务开始阶段另记录连接池使用量、上限与累计等待次数。池指标是进程汇总值，不能单独证明某个请求等待了连接。

诊断区分上下文取消、截止时间、数据库取消查询、连接耗尽、锁不可用和数据库不可用。HTTP 继续返回稳定的 unavailable；日志不包含查询词、对象 ID、账号、DSN、SQL 或驱动原始错误。

## 验证

ACAD-01 登记目录筛选、字面搜索、同教学班匹配、存量迁移与诊断脱敏测试。规模测试使用 557,205 个合成对象和同量历史记录，5 个请求并发、3 个数据库连接，覆盖课程与教师的 32 组查询。

补充测试覆盖任课集中于少量课程的分布、教师与分类不能跨教学班匹配，以及常见类别在有界首段没有命中时的完整回退和游标。生产测量单独记录数据库版本、资源限制、连接池初始化与查询样本。

测试先在旧表上创建索引，再重跑迁移并核对对象与历史数量。性能输出记录 p95、最大耗时和错误数；运行环境与实际生产验收由 ops 的接续说明记录。目标为约定负载下各组合 p95 小于 300 ms。
