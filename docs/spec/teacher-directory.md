# 教师目录标记

教师目录采用并集规则：有课程授课记录，或者已经与学校公开教师主页唯一匹配，满足任一条件即可展示。授课记录来自任课关系、教学班、学期开课和课程的完整关联。历史学期仍属于授课记录。

## 数据与接口

迁移创建 teacher_directory 和 teacher_site_sources。标记分别保存 teaching、official、匹配姓名、院系、主页和更新时间。两种依据可以同时成立。原始工号、官网简介和联系方式不进入标记表。

产品装配为 PostgreSQL Repository 设置 RequireTeacherDirectory=true。Repository 在 SQL 中过滤无标记教师，范围包括列表、名称搜索、详情、批量引用、合并解析、筛选选项、摘要计数和搜索的当前状态核对。分页前执行过滤。

目录维护使用 TeacherCandidates、RefreshTeachingDirectory 和 ImportTeacherSites 三个 Go 公开接口。接口要求导入权限和对应学校范围。候选分页最多 500 条，官网完整快照最多 20000 条。学校适配器不能直接写 catalog 表。

TeacherCandidates 只返回目录 ID、姓名、院系名称、已批准职称和授课事实，供私有维护任务匹配。它不受公开标记过滤影响，也不返回原始来源工号。客户端没有此维护入口。

具有对应学校维护权限的管理员仍可查看、合并和停用隐藏档案。Service 为这类维护操作选择独立的读取上下文，HTTP 参数不能开启。普通用户读取、搜索和统计继续检查标记，源数据导入也不会自动开放教师档案。

## 刷新规则

教师与任课关系写入时，在同一事务内批量更新受影响教师的授课标记。课程完整同步后再调用 RefreshTeachingDirectory，核对全部授课依据并补齐旧安装缺少的标记。历史学期和停用前的授课记录继续有效。

官网完整抓取成功后，适配器按姓名和单位匹配，再调用 ImportTeacherSites 原子替换官网依据。任一依据为真即保留教师。候选集合摘要绑定全部目录姓名和院系，提交时持有学校写锁复核，拒绝匹配后新增同名档案的情况。

官网快照包含来源、观测时间和递增修订。相同修订与内容重复提交返回当前结果，不再写审计。相同修订对应不同内容、旧修订或匹配对象已经改变时拒绝整个快照。来源数据、标记、审计和 outbox 在同一事务提交。

官网刷新失败时保留上一完整集合。新快照中已经消失的官网记录撤销 official，已有 teaching 继续生效。姓名或院系 ID 变化后，原官网匹配不能继续单独授予展示资格，等待重新匹配。

已有目录对象不会因本规则删除，来源历史、选课证据和评价资格继续归所属模块管理。本人历史选课的最小名称接口保留，用于解释本人记录；公共教师档案仍检查目录标记和当前内容准入。

## 场景与验证

| 场景 | 通过条件 |
| --- | --- |
| CAT-TEACHER-01 | 授课、官网、两者同时成立均可展示，无依据教师不能从详情、列表、筛选、计数或搜索中读取 |
| CAT-TEACHER-02 | 重放与并发只写一次官网审计，失败回滚，旧修订拒绝，官网撤销保留授课依据 |
| CAT-TEACHER-03 | 名称或院系变化立即阻止旧官网匹配，跨学校维护和无权限候选读取被拒绝 |

执行 scripts/check-with-postgres.sh，使用真实独立数据库与运行身份检查事务、并发、权限、查询结果和实际标记变化。实际生产迁移、标记导入及后端版本由私有运维交接记录。
