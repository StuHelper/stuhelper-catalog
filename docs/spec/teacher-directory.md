# 教师目录标记

教师有截止学期及以后的有效授课记录、有效官网匹配，或经核实后获批的独立主页资料时，可进入公开目录。默认授课截止学期为 2023 秋。官网匹配和获批的独立资料不受学期限制。

## 数据与接口

目录标记分别保存授课、官网匹配和经核实的独立资料依据。独立资料通过目录和搜索向现有准入范围内的用户展示，学校统计单列，不计入官网匹配。官网资料、照片和人工决定由 catalog 单独保存。目录职称与院系仍使用教务数据。官网资料不参与目录检索、摘要计数或本人选课证据。

产品装配同时启用 RequireTeacherDirectory 和 RequireDirectoryProjection。列表、详情、筛选、摘要和搜索使用同一已发布投影。重建规则见[可展示目录投影](directory-projection.md)。

目录维护使用 TeacherCandidates、RefreshTeachingDirectory 和 ImportTeacherSites 三个 Go 公开接口。接口要求导入权限和对应学校范围。候选分页最多 500 条，官网完整快照最多 20000 条。学校适配器不能直接写 catalog 表。

TeacherCandidates 只返回目录 ID、姓名、院系名称、已批准职称和授课事实，供私有维护任务匹配。它不受公开标记过滤影响，也不返回原始来源工号。客户端没有此维护入口。

具有对应学校维护权限的管理员仍可查看、合并和停用隐藏档案。Service 为这类维护操作选择独立的读取上下文，HTTP 参数不能开启。普通用户读取、搜索和统计继续检查标记，源数据导入也不会自动开放教师档案。

## 教师页资料

使用 GET /api/v1/catalog/objects/{id}/teacher-homepage 读取可展示的主页资料。该接口复用当前教师目录准入，允许按字段省略官网姓名。整个资料不可展示时返回空对象。

教师详情和摘要仍支持 `include_teacher_homepage=true`。旧版严格校验要求官网姓名非空。官网姓名隐藏或未获准展示时，这两个旧入口省略整个 `teacher_homepage`。目录列表和批量查找不带主页资料。

主页资料可包含官网姓名、职务、学历、学位、学科、导师身份、邮箱、电话、办公地点、入校任教时间、个人简介、研究方向、其他字段和文字栏目。目录姓名、职称与院系使用教务对象。

可选字段缺失时省略，空列表返回空数组。按字段限制长度，每条资料的 JSON 最多 1 MiB。教师资料响应包含照片的 StuHelper 地址、类型和尺寸。官网主页链接和采集时间留在内部。

照片为已验证的 JPEG 或 PNG，每张最多 2 MiB、每边最多 4096 像素且总面积最多 8,388,608 像素。照片的同源接口重新检查访问资格、教师可见性、当前发布的资料和照片规则。客户端以已认证请求读取二进制，响应禁止缓存。

## 正文媒体

GET /api/v1/catalog/objects/{id}/teacher-homepage/media 返回当前可展示的正文媒体。按官网顺序提供最多 1000 项，每项标明所属的简介、研究方向或栏目。纯媒体栏目也按标题执行白名单。显示标题使用纯文本。

校验通过的正文图片使用 StuHelper 同源地址，响应附类型、尺寸和字节数。每张最多 20 MiB，每边最多 8192 像素，总面积最多 16,777,216 像素。超过限制、无法取得或校验失败的图片链接到同一教师的学校原内容页。

视频和全部附件使用可点击的原站链接。客户端在用户主动点击后打开外链。复制成功的图片以登录凭证读取二进制。图片 GET 和 HEAD 每次重查账号、当前学校、目录可见性及媒体归属，响应禁止缓存。

正文图片按内容摘要去重，数据库中的正文图片总容量为 2 GiB。超过总容量后保留已有有效副本，将新增复制转为原内容页链接，并记录该轮容量告警。刷新事务同时更新图片引用、资料和匹配。

## 刷新规则

源记录保留完整历史授课标记，供维护和旧版本读取。公开目录的 teaching 由投影根据有效课程、开课、教学班、任课关系及截止学期重算。同步的所有分页成功后才发布新投影。

历史任课事实仍可通过 HasTaught 供受信模块核对教师回复的披露要求。本人选课证据继续按账号隔离，目录截止规则不删除历史事实。

官网完整抓取成功后，适配器按姓名和单位生成候选，catalog 在学校写锁内复核候选集合，并按现有人工决定计算有效匹配。人工绑定优先于自动结果。同一站点和教师各只能有一个有效匹配。

官网快照包含来源、观测时间和递增修订。相同修订与内容重复提交返回当前结果，不再写审计。相同修订对应不同内容、旧修订或匹配对象已经改变时拒绝整个快照。来源数据、标记、审计和 outbox 在同一事务提交。

官网刷新失败时保留上一完整集合。站点从新快照消失或被确认为不可用时，暂停官网展示依据及资料。人工决定继续保存，原站点重新出现时按决定处理。符合截止规则的授课依据继续生效。

目录姓名或院系变化后，旧自动匹配失效，等待重新匹配。人工绑定继续指向原目录 ID。目标停用或被合并后停止展示该绑定，管理员可撤销或重新绑定。

未启用目录投影时，授课、官网匹配与获批独立资料标记的变化同步更新教师搜索修订与浏览活动可见性。

已有目录对象不会因本规则删除，来源历史、选课证据和评价资格继续归所属模块管理。本人历史选课的最小名称接口保留，用于解释本人记录；公共教师档案仍检查目录标记和当前内容准入。

## 采集字段白名单与人工控制

采集快照保存来源事实。公开详情、摘要、照片和正文媒体按当前学校白名单筛出可展示内容，再核对人工覆盖、字段隐藏和整页状态。来源字段或栏目被人工覆盖后，所属正文媒体也停止展示。旧图片地址随隐藏、停止展示或匹配失效而撤权。

管理员明确提交的覆盖值优先于采集值，可补充原本缺失或不在白名单中的值。字段隐藏优先于覆盖值。撤销覆盖后使用当前获准展示的采集值。刷新保留学校白名单、覆盖与隐藏设置。

隐藏邮箱、电话或办公地点时，公开字段与栏目同时过滤已识别的重复值。多行值按行识别，匹配兼容空白和标点差异。无关的年份和短数字照常展示。

整页状态为 `visible`、`hidden` 或 `stopped`。隐藏可恢复，停止展示须管理员显式解除。两者都收回教师主页和照片，对应目录对象、教务职称、院系及评价仍按原规则公开。

学校管理员在 /api/v1/catalog/admin/schools/{school_id}/teacher-sites 下管理。GET、PUT /allowlist 读取、替换采集字段白名单。GET、PUT /teachers/{teacher_id}/homepage 读取或更新单名教师的主页。

GET /homepage-counts 分别提供授课、官网匹配和已核实人工资料依据的数量，同时给出三者并集。批准新增的教师待下一代目录投影发布后进入列表，独立依据与其他依据可重叠。

读取与修改要求同校 `catalog.maintain`。修改带 `expected_revision` 和 `Idempotency-Key`，空设置的初始修订为 0。审计、状态和幂等回执一起提交。单名教师设置的 PUT 回执只含教师 ID 与写入修订。使用 GET 读取当前设置。收到 `409 conflict` 后重读设置，再决定是否重试。

学校白名单逐一指定通用字段标签与栏目标题。人工覆盖或隐藏可按标签或标题选择。人工规则省略标签时作用于整个集合。同一规范化标签的重复项一起处理。覆盖一个分段栏目时，新正文整体替代同标题的原分段。PUT 省略旧规则时移除该规则；保留规则且省略 `override` 时撤销覆盖。

整组与逐标签规则合并后，最多保留 128 项有效人工通用字段和 64 项有效人工栏目。保存超限返回 `409 teacher_homepage_capacity_exceeded`。减少或合并人工项后再提交。

替代头像接受同源托管的 JPEG 或 PNG。Admin 上传及教师本人提交使用相同的 2 MiB、像素和格式限制。管理员可预览本校申请的替代头像。审批前的头像保存在受限的审核区域，公开地址仅返回当前已发布头像。

含头像的设置或申请使用 JSON 请求，最多 4 MiB。请求体超限返回 `413 payload_too_large`。图片实际格式、解码和像素校验失败返回 `400 invalid_input`。

## 教师本人更正请求

当前有效教师认证关联到目录教师后，教师本人可以提出更正、补充或隐藏。目录归属使用认证模块提供的有效记录。尚未匹配官网的教师也可申请。本人通过核实后，管理员批准发布的非空内容或替代头像可作为独立的目录可见依据。

教师页从 /api/v1/catalog/objects/{id}/teacher-homepage/requests 提交申请并分页读取本人回执。GET /api/v1/catalog/me/teacher-homepage/requests/{request_id} 读取单个本人回执，供站内通知定位。

提交携带 `Idempotency-Key`、提案、说明和目标字段。更正或补充提供建议的新值，隐藏申请可指向字段或整页。每个账号每分钟最多提交十条新申请。相同提交重放返回原结果。

管理员按学校分页查看待处理、已批准和已拒绝请求，在详情中读取申请内容。审批需要当前申请修订，批准同时需要教师主页控制修订。批准应用维护操作。批准发布新值前复核申请人的当前有效关联。处理结果及对本人可见的说明写入回执。

批准后的人工项超限时，返回 `409 teacher_homepage_capacity_exceeded`，申请继续待处理。减少或合并现有人工项后，使用当前修订重新审批。

终态处理、审计及通知事件在同一事务提交。站内通知仅提供申请编号和处理结果。通知跳转再次核对本人账号及教师归属。其他人可联系 `legal@stuhelper.com`。登录用户可通过 POST /api/v1/moderation/teacher-homepage-complaints/{teacher_id} 提交站内投诉，进入现有投诉队列。

## 官网刷新管理

管理接口位于 `/api/v1/catalog/admin/schools/{school_id}/teacher-sites`。GET /refresh 查看最近任务和标记人数，POST /refresh 提交增量或全量任务，GET /unmatched 保留旧版的未匹配站点列表。

查看要求 catalog.teacher-sites.read，触发要求 catalog.teacher-sites.refresh，并检查当前可管理学校。每次成功查看、触发、幂等重放及无权限请求均记录操作者、学校、操作和结果。审计失败时，读取或任务提交失败。

任务先持久排队，独立 worker 领取后抓取。手动和定时请求共用全局事务锁及唯一索引，同时最多一个排队或运行任务。相同操作人、学校、幂等键和内容返回原任务，内容变化或已有其他任务时返回 409。

定时任务每月执行一次增量，全量由管理员手动提交。增量读取完整名单，重抓新增、变化、缓存失效或净化规则变化的详情。未变化详情不按年龄自动重抓，官网未反映在名单中的详情变化由手动全量复核。

新入队的增量和手动全量任务分别最多运行 45 分钟和 8 小时，均含排队时间。实际截止时间以任务返回的 `deadline_at` 为准，幂等重放沿用原值。

worker 预留 10 分钟完成事务和 15 秒写入失败回执，取消时结束抓取进程组。进程崩溃后由到期处理记录 timeout，过期 worker 无法提交结果。

任务记录类型、触发方式、开始和结束时间、状态、毫秒耗时、请求数、站点数、四类标记人数和固定失败码。最近任务按数据库入队序号确定，同一时间戳不会选回旧任务。尚未取得的测量值为 null，失败信息不包含上游正文、URL 参数或身份字段。

完整结果将官网标记、未匹配快照、已校验的新目录投影和任务成功状态在同一事务提交。超时、截断、匹配候选变化或依赖故障保留上一份完整标记和未匹配清单。授课依据按当前目录重新统计。

旧版 /unmatched 返回站点摘要 ID、名称、单位、原因和同名候选数量。因姓名不存在、单位缺失或不一致、目录或官网有多个候选导致的未匹配记录沿用原原因代码。

每页一至一百条，按站点标识摘要排序，支持原因与姓名/单位字面子串 q 筛选。total 对应筛选后的数量，reason_counts 对应整份快照。游标绑定学校、原因、q 和快照修订，刷新后使用旧游标返回 409，客户端重新读取首页。

现有私有清单通过 ImportTeacherUnmatched 迁移，姓名和单位来自相同观测时间的净化快照。迁移不生成虚假的抓取记录。新刷新成功后替换当前清单，失败时保留原清单。

管理读取使用 PostgreSQL 一致快照，记录查看审计时保留原快照。读取不持有刷新或学校写锁，因此重建期间仍可查看运行状态和上一完整清单。

官网清单每校最多两万站点。姓名、单位和来源主页 URL 分别最多 256、512、512 字符。来源地址按学校校验规范路径及域名白名单，默认允许 shi.buaa.edu.cn。

任务历史最多一万条，满额返回 unavailable。PruneTeacherRefreshRuns 每次最多清理一千条旧终态记录，保留运行中、排队中及各校最新任务。

清理终态任务时，同一事务把最终结果保存为长期幂等回执。相同请求仍返回原任务，复用幂等键修改内容返回 409，超时执行者无法重新提交。

| 场景 | 预期结果 |
| --- | --- |
| CAT-REFRESH-01 | 并发手动与定时只接受一个任务，重放返回原任务，超时后旧执行者不能写入 |
| CAT-REFRESH-02 | 未匹配清单按原因分页，失败保留完整快照，跨学校及撤权访问拒绝并审计 |
| CAT-REFRESH-03 | 审计失败回滚任务，HTTP 拒绝匿名、越权及未知输入字段 |

## 人工处理

GET /review/sites 列出官网站点、原因、同名目录候选和当前人工决定。默认 `status=pending`，可用 `decided` 查看已有人工决定，`all` 查看全部。已移除站点保留的决定也可查看。站点 ID 是按学校隔离的 SHA-256 摘要。

GET /review/teachers 列出目录教师、原因和同名站点候选。默认 `status=unmatched`，可用 `all` 查找任何有效的同校教师作为绑定目标。两侧均支持字面子串搜索，按 ID 分页，每页最多一百条。

列表默认每页二十条。候选条目过多时会在页面正文达到 3 MiB 前提前分页。每条记录最多返回一百个当前有效候选，`candidate_count` 保留快照计数。

`total` 是筛选后的记录数，`next` 为空表示已到末页。快照或人工决定变化后，旧游标返回 409，客户端重读首页。

两个列表均要求 `catalog.teacher-sites.read`。PUT /review/sites/{site_id}/decision 要求 `catalog.maintain`。服务端每次检查管理员当前可管理的学校。

PUT 需要 `Idempotency-Key`、`action` 和 `expected_revision`。人工绑定用 `bind` 并附目录 `teacher_id`，标记不对应用 `reject`，撤销用 `revoke`。新绑定要求官网站点可用、同校目标有效。

客户端取站点当前 `decision_revision` 作为预期修订，首次为 0。撤销后保留修订并重新按自动规则计算。相同请求返回原结果，改用相同键请求不同内容或修订不符时返回 409。

人工决定、幂等回执、审计及匹配变化在同一事务中提交。审计记录操作人、学校、站点、操作和结果，绑定时附目录教师 ID。公开详情只显示当前有效匹配的资料。
